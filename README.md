# 27 October 1999 — motion summary

A ~68-second motion-graphics summary of the 1999 Armenian parliament shooting, built with [Remotion](https://www.remotion.dev).

```bash
npm install
npm start        # open Remotion Studio to preview and edit
npm run render   # render out/oct27-1999.mp4
```

Scenes live in `src/Oct27.tsx`; scene lengths are in the `SCENES` object (frames at 30 fps).
