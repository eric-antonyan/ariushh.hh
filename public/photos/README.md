# Photos

Drop photos here and they replace the illustrated placeholders automatically (`.jpg`, `.png` or `.webp`):

| File name        | Used for                                    |
|------------------|---------------------------------------------|
| `vazgen.jpg`     | Vazgen Sargsyan (leaders + aftermath scenes) |
| `demirchyan.jpg` | Karen Demirchyan                            |

Put the author/licence of each photo in `src/data/photo-credits.json` (e.g. `"vazgen": "Wikimedia Commons, CC BY-SA 4.0"`) so it appears in the credits.
